Native speech-to-text for Linux.

**Why hyprwhspr?** There are a lotta dictation apps. This one is built ground-up for performance and stability: your hardware will auto-optimize to the **best possible accuracy and speed**. Actively maintained, at the leading edge, fully featured, strictly offline unless you use an API, and works on both Wayland and X11.

Install with the [quick start](https://github.com/goodroot/hyprwhspr#quick-start), then:

- [Configuration](/docs/configuration/) — the config file, validation, minimal setup
- [Recording modes](/docs/usage/recording-modes/) and [hotkeys](/docs/usage/hotkeys/) — how you dictate
- [Choosing a backend](/docs/backends/overview/) — which model, on which hardware
- [Troubleshooting](/docs/troubleshooting/) — when it doesn't
